# Logos de empresas

Suelta aquí los logos de las empresas. Se referencian desde
`src/components/ProfessionalExperience.astro`.

## Sotec Consulting
- Archivo esperado: **`sotec.svg`** (ideal) o `sotec.png`.
- Se referencia como `/logos/sotec.svg`.
- Si cambias la extensión a `.png`, actualiza la línea `logo:` del componente.

## Recomendaciones
- Preferible **SVG** o **PNG con fondo transparente**.
- Cuadrado (p. ej. 512×512) para que encaje en el recuadro redondeado.
- Si el archivo aún no existe, la tarjeta muestra la **inicial** de la empresa
  como fallback (no rompe la web).

> El logo de OriginPath se importa desde `src/assets/logorigin.jpg`.
